# Security policy

## Reporting a vulnerability

Please do not disclose clipboard-data exposure or other security-sensitive issues in a public GitHub issue.

Until a dedicated private reporting address is published, contact the repository owner through the private contact option on their GitHub profile and include only a high-level description initially. Do not include real passwords, tokens, personal conversations, or clipboard history.

## Supported version

Only the latest release receives security fixes during the pre-1.0 public testing period.

## Security model

ClipGrid is intentionally local-only. It does not provide cloud synchronization, remote APIs, accounts, analytics, or advertising. Concealed and transient pasteboards are excluded on a best-effort basis, but users should still treat clipboard managers as sensitive software and clear or pause history when appropriate.
