# ClipGrid Privacy and Release Audit

**Audit date:** 1 September 2026

**Audited revision:** `74554f9` (`main` before App Store-readiness changes)

**Scope:** Public Git history, Swift source, package manifest, build workflow, support resources, and marketing claims.

## Executive result

ClipGrid's source supports its local-only positioning:

- No third-party Swift package dependencies.
- No network client, analytics, advertising, account, tracking, or cloud-sync implementation found.
- No requested Accessibility or Input Monitoring permission.
- Global shortcut uses Carbon `RegisterEventHotKey`.
- Concealed, transient, and auto-generated pasteboard types are skipped.
- Clipboard history is bounded to 35 items and users can pause, delete, clear, or quit.
- Complete Git history scan found no private keys, GitHub tokens, AWS access keys, or hardcoded credential assignments matching the audit patterns.

The exact signed Mac App Store archive must still be inspected and tested on macOS. Source review alone cannot prove the behavior of an unbuilt submission artifact.

## Dependency audit

`Package.swift` defines one executable and one test target. It contains no external package declaration. The app uses Apple frameworks only:

- SwiftUI
- AppKit
- Foundation
- Carbon
- CryptoKit

CryptoKit is used to calculate deterministic SHA-256 clipboard fingerprints for deduplication. It is not used to encrypt, transmit, or expose user data.

## Network audit

Searches across the Swift source found no:

- `URLSession`
- Network or WebSocket client
- Analytics SDK
- Crash-reporting SDK
- Advertising SDK
- Authentication/account client
- Cloud synchronization client

The App Sandbox entitlement file declares only `com.apple.security.app-sandbox`; it does not declare outbound or inbound network access.

**Archive verification still required:** inspect linked frameworks and runtime traffic for the exact TestFlight build.

## Clipboard processing

`ClipboardStore` monitors `NSPasteboard.general` every 150 ms while monitoring is active. Supported values are:

- Text
- HTTP/HTTPS links
- PNG/TIFF images
- Local file/folder references

Before creating an item, ClipGrid excludes pasteboards containing:

- `org.nspasteboard.ConcealedType`
- `org.nspasteboard.TransientType`
- `org.nspasteboard.AutoGeneratedType`

This is best-effort protection because originating applications must mark their pasteboards correctly.

## Stored fields

The local JSON history can contain:

- Clipboard text or URL
- Image bytes
- File paths
- Copy timestamp
- Pin state
- Source application name
- Source bundle identifier
- Small source-application icon representation

Clipboard values are sensitive even though they are not transmitted. The policy and listing must not imply that local history is encrypted. Users can clear the stored history from ClipGrid.

## Retention and controls

- Maximum retained count: 35, matching the keyboard shortcut map.
- Duplicate payloads are moved forward rather than stored twice.
- Users can delete one item.
- Users can clear all history.
- Users can pause monitoring.
- Users can quit from the menu-bar menu.
- Uninstalling the app may leave Application Support data until macOS or the user removes the container.

## Permissions

The source uses Carbon `RegisterEventHotKey` for `⌥⌘C`. No Accessibility, Input Monitoring, Automation, Full Disk Access, Contacts, Calendar, Photos, Camera, Microphone, or Location permission API was found.

The app reads the frontmost application's public workspace metadata for best-effort source attribution. This can be inaccurate if the foreground app changes between the copy and capture.

## Logging

The only source logging found is operational hotkey registration/activation via `NSLog`. It does not include clipboard payloads, file paths, account data, or identifiers. Verify Release console output from the archived build before submission.

## Secrets and repository history

The complete Git patch history was scanned for:

- PEM/OpenSSH private-key headers
- GitHub token formats
- AWS access-key formats
- Generic quoted API-key, secret, password, or token assignments

No matches were found. This pattern scan does not replace GitHub secret scanning or a specialized scanner if one becomes available.

## Residual risks requiring macOS/Apple access

1. A real Xcode application target/archive scheme is not present in the Swift Package repository.
2. App Sandbox behavior has not been executed on this Linux host.
3. Carbon hotkey behavior must be tested in the signed sandboxed app.
4. File-reference and source-icon behavior must be tested under the sandbox.
5. The exact archive's entitlements, linked frameworks, privacy manifest, signing, and network behavior must be inspected.
6. Clean-account and TestFlight testing must be completed on macOS.
7. Apple privacy, export-compliance, and age-rating answers must be confirmed against the uploaded artifact.

## App Privacy recommendation

If the exact release archive matches the audited source and runtime verification shows no transmission, the App Store answer **Data Not Collected** is supportable: ClipGrid processes data solely on-device for its core clipboard function and does not send it to Rudolf or a third party.

Any future analytics, crash reporting, network service, account, sync, or third-party SDK requires a new audit and corresponding policy/App Store disclosure before release.
